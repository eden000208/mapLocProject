# BSQ 轻量版实施范围

直接连接 MySQL，创建独立 bsq_app。现有明细仅 SELECT，映射由 datasource.yaml 配置。
账号密码；用户直接分配区县/营服/明文权限，无独立角色配置页。
管理员可使用全部菜单、所有有效小区及明文查看；分析员按区县/营服授权，空范围默认拒绝。所有用户只能访问自己的查询任务。
基站 CSV/XLSX upsert、校验/坐标预览/错误报告、维护。
地图矩形/多边形/圆/点选/搜索；按月查询本网/异网；分页/统计/历史复用/XLSX。
地图支持用户主动获取当前位置，展示定位点、精度范围及视口中心坐标；定位需要浏览器授权及 HTTPS/localhost，不保存独立定位记录。
小型线程池、取消/超时/限额/TTL、重启未完成任务标失败。
保留简易操作日志，不做审批/TOTP/回滚/覆盖导入/配置页/去重视图/复杂审计。
阶段 M0契约 → M1骨架 → M2模块并行 → M3集成 → M4验证交付。
主 agent 管公共模型/接口/部署；子 agent 管账号基站、前端、查询导出。
不创建测试库；用户于2026-10-10授权在 bsq_app 创建本网/异网表并使用明确标记的模拟明细验收。应用查询仍只读明细，初始化/演示命令显式写入 bsq_app；其他库不改。
